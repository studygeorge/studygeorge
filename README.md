## 👋 About me

I build products end to end — from the PCB and the enclosure to the API, the web app and the brand behind it.

- 🏭 **Tech entrepreneur** — building businesses in **manufacturing** and **instrument engineering**
- 🧩 **Full-stack developer** — TypeScript/Vue front-ends, Python & Node back-ends, Telegram WebApps and bots
- 🎨 **Product & web designer** — I design what I ship, not just implement someone else's mockups
- ⚙️ **Engineer** — 10+ years across production lines and commercial development
- 🔌 **Hobby:** electronics, 3D printing and solving hard problems with modern tech
- 💬 Ask me about IoT device fleets, MQTT, DIY machine building, or shipping a product solo
